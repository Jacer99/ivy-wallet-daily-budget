6. KEY ARCHITECTURAL FACTS
================================================================

Money:
  - Engine + new entities: Long minor units (TND = 3 decimals)
  - Ivy legacy: Double / BigDecimal
  - Conversion only at mapper boundary via CurrencyMinorUnits
  - NEVER Float, NEVER Double in new money fields

Time:
  - Instant → LocalDate via ZoneId parameter, never global

Budget pipeline:
  RoomDynamicBudgetConfigStore → GetDynamicBudgetSnapshotUseCase
    → DynamicBudgetRepository → DynamicBudgetMapper →
    DynamicBudgetEngine → BudgetSnapshot → mapToSafeToSpendCardState
    → SafeToSpendCardState → SafeToSpendCard composable

Reactivity:
  - TransactionRepository posts DataWriteEvent.SaveTransactions
  - HomeViewModel collects DataObserver.writeEvents via
    collectLatest and re-runs reload()
  - MutableSharedFlow buffered 16, DROP_OLDEST
  - LaunchedEffect(Unit) in uiState() handles first paint

State class shapes (for reference):
  SafeToSpendCardState:
    Loading | NoBudget | Active | Error
  Active fields:
    remainingAllowanceMinorUnits: Long
    openingAllowanceMinorUnits: Long
    todayChargesMinorUnits: Long
    tomorrowProjectionMinorUnits: Long?
    message: SafeToSpendMessage?
    paydayLabel: String? (after Task A)

  BudgetSnapshot fields:
    periodStart, periodEnd, capacity, periodSpentRaw,
    periodReserved, periodRemaining, daysRemaining,
    openingAllowance, todayCharges, remainingAllowance,
    tomorrowProjection

  DynamicBudgetConfig fields:
    id, periodType, budgetLimitMinorUnits, currencyCode,
    includedAccountIds, includedCategoryIds,
    includeIncomeInBudget

  BudgetPeriodType (sealed):
    Weekly | Monthly | Salary(payday: Int) | Custom(start, end)

11. WORKING WITH GEMINI — RULES
================================================================

Gemini in Android Studio is a code assistant. It CANNOT run
shell, git, gradle, or process invocations. Attempts hang the
session. Every prompt must include:

  "Do NOT run any shell commands, git commands, gradle commands,
   or process invocations."

Gemini CANNOT:
  - Copy or move binary files (PNGs, .webp)
  - Run the Image Asset wizard (manual Android Studio tool)
  - Persist files across a corrupted session (start fresh per task)

Gemini CAN:
  - Read any file in the repo
  - Edit any file in the repo
  - Grep and search

Every prompt must end with:

  "Do NOT claim 'Build finished successfully.' I run Gradle
   locally. Reply inline only. Do NOT create plan or walkthrough
   artifact files."

Gemini quirks to watch for (learned this project):
  - Claims "build succeeded" without running Gradle → ALWAYS
    verify locally
  - Writes `./gradlew assembleDebug` (macOS style) → user runs
    `:app:assembleDebug` on Windows
  - Sometimes invents shadow operators like Unit.thenInvokeAfter
    → reject
  - Sometimes uses `not in` instead of `!in`, `HALF_DOWN` instead
    of `HALF_UP`, `verify` instead of `coVerify`
  - Writes tests to the wrong source set occasionally
    (src/main/java instead of src/test/java or src/androidTest/java)
  - Adds unused wildcard imports → clean up

Model rotation: start a fresh Gemini session per task to avoid
thought_signature corruption.
